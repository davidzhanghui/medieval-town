# 中世纪城堡 · 3D 可交互场景

纯前端 Three.js 场景，所有纹理（石墙、瓦片、木纹、草地、水面、旗帜、茅草、农田、土路、鹅卵石、灰泥、布篷）都是 Canvas 程序化生成，无外部图片依赖；音效也没有——"钟声"用钟体摆动和钟室透出的暖光来表达。

场景分五层：**城堡**（主楼、城门楼、四角塔、城墙、护城河、吊桥）、**村落**（9 幢农舍、农田、羊群、农夫、土路）、**镇中心**（市集广场、木筋楼、酒馆、铁匠铺、教堂钟楼与堂内、墓园）、**工匠区**（小溪、石桥、水磨、风车、采石场、伐木场、作坊、陶窑）与**前哨**（木栅要塞 + 石砌望楼）。

城堡的其余三个方向另有**修道院**（西北）、**比武场**（东北）与**朝圣客栈**（西），各自有一条土路通回城堡。

这三处又各自向外延伸出五处**外围场景**——修道院周边的圣泉、谷仓、济贫院、石匠场、隐士居，比武场周边的校场、马市、场外集市、甲胄匠、伤兵帐，客栈周边的渡口、路边神龛、篝火营地、货栈、荒村。合计 15 处，全部由土路串在母场景的干道上。

在这 15 处之外再向外一倍，还有一圈**更远的地界**——墓地、磨坊、羊圈、蜂场、废教堂，牧马场、箭术场、木料场、马具匠、老骑士宅，收税关卡、瞭望塔、病舍、水磨人家、绞架。又是 15 处，草地、树林、雾与阴影的范围都跟着扩到半径六百多米。

地图的东半边另有一条**大河**自东南流来，把地界分成两半：西岸是老城堡与老镇，东岸是新开的**渡口镇**，两座石桥把两边连起来。河的北面是一整条**山脊**，山脚一道**瀑布**落进**镜湖**，再往南是一湾**花甸**。水上有**水鸟**盘旋，水里有**鱼群**，草上有**蜻蜓与蝴蝶**。

在此之上还有一层**昼夜活动**：摊位天亮开张、天黑收摊盖布；镇民按作息到点回家、天亮再回来；铁匠白天打铁溅火星；整点敲钟报时。

世界本身又扩大了：草地半径从 900 米扩到 **2000 米**，南面是**海**，外环（半径一千到一千七百米）新增**十个各有特色的远方村镇**——灯塔港、铁砧矿镇、酒乡、古橡镇、羊毛染坊镇、云顶修道院、沼泽水乡、雪岭长屋、学者镇、商队集市——由十一条主干道串回原有世界；左下角有一张**可点击的小地图**。详见下面「外环十镇」一节。

## 运行

```bash
# 在本项目目录（medieval-castle/）下
python3 scripts/serve-nocache.py 8765 .
```

然后打开 http://127.0.0.1:8765/

用 `scripts/serve-nocache.py` 而不是 `python3 -m http.server`：后者只发 `Last-Modified`，浏览器会按"距上次修改时长的 10%"做启发式缓存，改完 JS 刷新后拿到的还是旧模块。

没有 python 时，可以用 Node 的静态服务（同样关缓存）：

```bash
npx http-server . -p 8765 -c-1
```

（必须用 HTTP 服务打开，`file://` 下 ES Module + importmap 会被浏览器拦截。）

## 城堡外：村落、镇中心、工匠区、前哨与四个方向的邻景

### 村落

- **9 幢农舍** — 石砌墙基 + 夯土墙 + 木筋立柱 / 斜撑 + 茅草坡顶，每幢带门板、铁门环、正面与侧面两扇夜亮窗、半开百叶、砖石烟囱
- **炊烟** — 5 根烟囱升起缓缓上飘、逐渐淡出的白烟（精灵池复用，入夜减弱）
- **农田与稻草人** — 6 块带田垄的农田，4 个穿草衣戴斗笠的稻草人
- **道路** — 城堡吊桥前分岔的主路 + 通往要塞的支路，按折线生成的土路带
- **村口** — 一口带辘轳与茅草顶的水井、编条篱笆围出的院子、板车、柴垛
- **牲畜** — 26 只低头啃草、偶尔抬头的绵羊；20 只走动啄食的鸡
- **农夫** — 11 名手持镰刀 / 锄头 / 干草叉的村民，部分原地干活、部分沿路走动

### 镇中心

土路从村口往西南再走一段就到了镇上——这里是「村」升级成「镇」的地方，房子开始沿街成排。

- **市集广场** — 26×20 的鹅卵石铺地（不规则石块 + 青苔泥渍），四周压条石、四角留排水石；正中三级台阶上的石十字，是地标也是宣判的地方
- **五个市集摊位** — 面包 / 鱼 / 苹果 / 布匹 / 陶器，各配一种条纹布篷（红、蓝、绿、黄、紫），柜台下有挡板、旁边有摊主的小凳
- **7 幢木筋楼** — 石砌墙基 + 灰泥填充墙 + 深色木骨架（立柱、横梁、斜撑、二层短柱），二层向外挑出 0.32 米并露出托梁，红瓦双坡顶配封檐板、石烟囱；正背两面都有夜亮窗
- **酒馆** — 加宽的木筋楼，铁艺弯臂挑出酒杯招牌，门口两条长凳和一只当桌子用的木桶
- **铁匠铺** — 正面敞开的石木棚，后墙炉膛（煤块自发光 + 炉火光晕 + 点光源）、木墩上的铁砧、淬火水桶、墙上工具和成堆铁料，砖烟囱从后坡穿出
- **教堂** — 钟楼（束带层、四面钟室开口、悬挂的铜钟、雉堞、四棱尖顶与十字，整点会摆）；中殿是真能走进去的：券门（ExtrudeGeometry 挖半圆券洞 + 券石环）、两列石柱与拱肋、五排十张面朝祭坛的长椅、祭坛（台阶、石台、麻布、金十字、烛台）、两盏吊灯
- **墓园** — 中殿北侧围墙围出的一片坟地：土色地面、三段压顶矮墙、北墙开一道带石门柱与半开铁叶的小门、约 30 块高低不一的墓碑（圆顶 / 尖顶 / 十字架）、墙角的石十字与一棵紫杉；单独做成可点击热点
- **街景** — 四盏铁艺路灯（夜里点亮、灯罩发光并投暖光）、石凳、板条箱木桶、晾衣绳
- **镇上的人** — 5 名摊主、8 名顾客（部分沿广场来回走）、1 名挥锤的铁匠、2 名在酒馆门口举杯闲聊的酒客、1 名教堂前的神职

### 工匠区（城墙外）

小溪从北边林子流下来，穿过作坊区往南去——磨坊、窑、采石场都得挨着水或石料。

- **小溪与石桥** — 按折线生成的带状水面（带流动的波纹与凹凸贴图）、两岸芦苇；跨溪的石桥是真正的半圆券拱（由跨度与矢高反解半径）
- **水磨坊** — 砖石磨房 + 红瓦坡顶 + 侧挂水轮，水轮随水流转动
- **风车** — 锥形石塔身 + 板岩穹顶 + 尾杆，四片格栅帆（白布蒙面）持续旋转
- **采石场** — 阶梯状下挖的石坑、切好的条石堆、凿石工具与半成品
- **伐木场** — 敞棚、锯架、成堆原木与木屑
- **四间作坊** — 陶匠、箍桶匠、织工、补锅匠，各带自己的工具与半成品
- **陶窑** — 圆顶砖窑，窑口透出炭火余烬的光
- **晒场** — 三组晒架，晾着皮子与布匹
- **工匠** — 15 名匠人散在各处干活

### 集市节庆

集日是镇上最热闹的时候，彩旗、五月柱、火盆和长桌都在广场上。

- **两串三角彩旗** — 横跨广场的木柱之间，绳子按抛物线垂下去，旗子交替四个配色
- **五月柱** — 石座 + 木柱 + 柱顶花环与金球，八条彩带从柱顶斜拉到地面，节庆时整圈缓缓旋转
- **花环拱门** — 立在大路进广场的东口，半圆拱上铺满叶子与花
- **四座铁火盆** — 三脚铁架 + 火盆 + 炭火，集日期间一直点着，天黑后烧得更旺
- **两条节庆长桌** — 交叉支架、两侧长凳，桌上面包、奶酪、酒壶、苹果摆了一排
- **赶集的驴车** — 车板、辐条车轮、车辕、两头挽具，驴有头颈耳腿尾；从拱门下一路赶到广场东南角停稳，车轮与驴腿随行进转动
- **铁匠火星** — 白天铁砧上会溅出一小把金色粒子（带重力、逐渐冷却变色）

### 前哨要塞

- **夯土高台** — 圆角矩形台基，南面 8 级石阶上来，两侧带收坡矮墙
- **木栅围场** — 尖头木桩围一圈，四角加粗角柱，南面留门
- **门楼** — 四柱木构 + 茅草顶 + 两扇半开铁箍木门，门外左右各 1 名卫兵
- **石砌望楼** — 束带层、箭孔、外挑城垛平台、楼顶旗杆；垛口上 1 名哨兵
- **院内** — 茅草顶营房、石圈火塘、板条箱与木桶、旗杆，另有 1 名绕院巡逻的守卫

### 修道院（西北）

城堡往北绕过林子，院墙围起一方 80×64 的院落，院门朝东南正对城堡方向。

- **院墙与门楼** — 压顶石墙四面包起，东南留一道门楼：两座 1.5 米厚的方墩、石梁、半圆券、两扇外开的木门
- **回廊** — 四面围合的两层石构，板岩双坡顶；底层是一圈连续的小圆券柱廊（每面 6 跨），廊上有四坡小顶与女儿墙，二层每面两排小窗
- **方形庭院** — 回廊围出的空地，正中立一座石日晷
- **药草园** — 十字小径把园子分成四畦，每畦 5×5 株药草（三种绿），畦边压石
- **礼拜堂** — 16 米长的单廊小堂，半圆后殿，两侧各三扇尖券窗（玻璃、券石环、窗台），西端有一朵玫瑰窗与一道券门；一侧立 11.5 米高的方钟楼，四面开口，悬一口会随钟声摆动的铜钟，四棱尖顶压十字
- **鱼塘与果园** — 院墙西侧一方带石岸的水塘（有倒影），南侧 4×4 的果树方阵
- **修士** — 黑褐会衣的修士在药草园除草、回廊下走动、礼拜堂里进出，夜里回各自的居所

### 比武场（东北）

- **跑道** — 两条平行木栅夹出 58×20 的场地，两端半圆收头；中间一道及腰隔栏（tilt），栏顶交替红白布幔，两端各立旗
- **两道看台** — 南北各一道阶梯看台，三级踏步 + 长条座板，顶棚前低后高、前檐挂红色帷边，后排砌挡墙
- **入口门楼** — 跑道东端两根粗木门柱、门楣与横匾，平顶小檐压两道瓦坡，两侧挂幡
- **骑士营帐区** — 北侧三座圆锥顶彩绘帐幕（红 / 蓝 / 绿 / 紫竖条纹）、马桩与缰绳、草料堆、兵器架
- **五柱靶** — 西端两座：立柱 + 十字横臂，一端盾牌一端沙袋
- **场上的人** — 两名骑士在跑道西端并辔待发、南北看台上共十余位观众、营帐区的随从与马夫，天黑后各自散去

### 朝圣客栈（西）

大路西头的一座车马店，主楼临街，后面围出能赶车进来的院子。

- **主楼** — 石砌一层 + 木筋二层（出挑 0.8 米，托梁外露），红瓦双坡顶、封檐板、石烟囱；券门带门环、两扇一层窗、五扇二层窗，铁艺弯臂挑出一块木招牌，牌上是只酒杯
- **车马院** — 三面石墙围合，南面留 5.6 米宽的车门，两侧门墩压顶，两扇铁箍木门向外张开；院里夯土地面带两道车辙
- **马厩** — 敞开的长棚，四个栏位、每栏一个草料槽，墙上挂挽具
- **附属** — 茅草顶水井、草料棚（三个草垛）、猪圈（三头小猪）、拴马桩（两匹马）、木桶木箱与晾衣绳
- **旅人** — 主楼门口的店主、卸货的伙计、院里的马夫、井边打水的、靠在猪圈边的旅人，夜里陆续进屋

## 三处母场景各自向外延伸的五处

母场景是「一个院、一块场、一间店」，外围是它赖以活下来的东西：修道院要有水、有粮、有施舍的地方；比武场要有练兵的校场、换马的市、卖东西的场外集市、修甲胄的匠人、抬伤员的帐；客栈要有过河的渡口、上路前的祈祷处、赶路人歇脚的营地与货栈。这些不是装饰，是把一座建筑撑成一片地界的那圈东西。

### 修道院周边（西北）

- **圣泉** — 石砌圆池 + 四根方墩撑起的石亭，池边三级台阶下到水面；北面壁龛里供着圣人像，井栏上系满布条
- **谷仓** — 修道院的什一税仓：石砌墙基 + 木构仓身 + 大坡度茅草顶，山墙留高处的通风口，门前停着板车与秤
- **济贫院** — 一排低矮的石木长屋，门前长凳上坐着等粥的人，烟囱里冒着细烟
- **石匠场** — 两级台地的采石坑（每级是一圈向下坐的实心石框，内壁就是坑壁），坑边有起重吊架、切好的条石与凿石工棚
- **隐士居** — 一间连着小祈祷室的石屋，篱笆围出的小菜畦，屋后一处土穴

### 比武场周边（东北）

- **校场** — 夯土围场，木桩、草靶、试剑石、兵器架；两名侍从在场上对练
- **马市** — 木栏围出的几个马圈、拴马桩、草料棚与称马的台子，马贩子牵着马踱步
- **场外集市** — 比武日临时搭起的一排货摊，条纹布篷、酒桶、烤架与看热闹的人
- **甲胄匠** — 方顶大帐改的工棚，帐下是铁砧、皮围裙、挂在架上的半成品胸甲与头盔
- **伤兵帐** — 比武场边上的救护所：帆布大帐、铺草的行军床、煮沸的水锅与晾着的绷带

### 客栈周边（西）

- **渡口** — 一条自北向南的河，木栈桥伸进水里，岸边拴着平底渡船，对岸立着指路桩
- **路边神龛** — 一人多高的小石龛，龛内一尊风化的圣像，脚下堆着旅人留下的供物
- **篝火营地** — 一圈碎石围出的火塘，周围几顶半塌的帐篷与横倒的原木当坐凳
- **货栈** — 石台基上的木构大屋，南面伸出一条卸货月台，门口堆着货包与木桶
- **荒村** — 五幢塌了顶的农舍，草皮被踩秃的土斑，井台空着，烟囱冷透。**刻意不留人**——这是被放弃的地方

## 再向外一圈：第二圈的十五处

## 河东：大河、群山、瀑布与镜湖

地图东侧原本是一片空草地，现在是一条从东南流来的大河把地界分成两半。河宽 22~38 米，沿一条十五个点的折线走，从东北的山脚一路蜿蜒到西南出图。

- **大河** — 按折线生成的带状河床（比水面宽 16 米）、浅水层、河心深水层，中间随段分布着十几处沙洲；两岸是卵石滩、芦苇与香蒲，河沿每隔一段种着垂柳
- **群山** — 东边一整条山脊，六座山（最高 205 米），其中三座过雪线。山体是极坐标系下的高度场 + 顶点色，不是锥体：山脚泥岩色过渡到山腰裸岩，雪线之上再渐变成雪，沟脊带一点明暗；山腰按坡度撒了松林，山脚散着碎石
- **银线瀑** — 北山南麓断开的崖口，二十米宽的水从二十六米高处落下。崖壁是二十多块噪声推过的岩块叠出来的，三排由高到低；水口两侧各垫一块高石把缺口收成竖缝，崖顶的岩缝里长出七棵松树，崖脚半埋乱石
- **水帘** — 三层同宽的半透明薄片，透明度、贴图密度与前后错开量各不相同，水纹贴图持续向下滚；崖下有石圈围出的落水潭，潭面铺着二十六片泡沫，七片水雾在潭上缓缓起伏
- **镜湖** — 瀑布下游的浅洼，30×34 米的水面，底床比水面大一圈；睡莲盘与白花散在水上，岸线一圈芦苇与香蒲
- **花甸** — 河湾北岸的一片草坡，花成簇地开（五种颜色，一簇同色），越靠边越稀，边界自然过渡

### 渡口镇（Fordham）

河东的第二个镇子，面积与西岸老镇的镇中心一样大（广场同为 26×20），但吃的是河上的饭。镇子的长轴顺着河岸摆，北面一整个街面都贴着水。

- **广场** — 与老镇同一套鹅卵石铺地、石十字、四角路灯；五个摊位、7 幢木筋楼、酒馆、铁匠铺、教堂一应俱全
- **沿河一条街** — 码头（木栈桥 + 系船柱 + 货堆 + 绞盘）、鱼市（敞棚下两张摆满鱼的案子、墙上挂渔网）、河畔货栈（石基木身、二楼卸货门与吊臂）、老渡口（摆渡小屋 + 伸进河里的栈台 + 拴在旁边的渡船）、水磨（下射水轮随水转）、洗衣石阶
- **镇门** — 西头的石拱门，正对从西桥下来的大路，门柱上挂两盏灯
- **镇上的人** — 5 名摊主、7 名顾客、1 名装卸工、1 名在石阶上洗衣的妇人

### 两座桥

河是东西向的，桥面因此转成南北向横跨，两座都是真拱桥。

- **西桥** — 跨度 36 米、桥面宽 7.4、拱高 3.4，接老镇这一侧的引桥
- **东桥** — 跨度 34 米、桥面宽 7.0、拱高 3.2，接渡口镇
- 桥身由跨度与矢高反解圆弧半径，26 节石板沿曲线铺；桥体用 ExtrudeGeometry 挖出主拱与两个泄洪孔，栏板与望柱也按同一套曲线摆放

### 水鸟、鱼与虫

- **水鸟** — 两群（湖上 16 只、河湾 10 只），各自绕圈盘旋、翅膀按相位扇动，飞得有高有低
- **鱼群** — 湖里 26 条、瀑布潭里 14 条，绕圈游动并摆尾
- **虫** — 三群蜻蜓与蝴蝶（花甸、湖畔、河滩），白天在草上乱飞，入夜淡出

### 性能策略

世界扩大后，同屏物体数量翻了几倍；如果不做处理，从港口朝北望去，旧世界一千多米外的几千个网格都会被画出来。所以引入了几层策略：

- **跟随相机的阴影盒**：阴影只覆盖注视点周围 110～520 米（按视野远近分四档），中心按光空间纹素吸附。比原来"一张图罩住全图"的纹素更细（最近一档 6 厘米），而且阴影图只在盒子移动 / 昼夜切换 / 每 4 帧时重画。
- **村镇整组剔除**：每个镇是独立的 `Group`，离相机远于 `showR` 就整组 `visible=false`，动画、炊烟、人物更新一并停掉；站在镇里时画调用只有 130～950 次。
- **远景信标**：镇子被剔除时，才显示一个很便宜的信标（灯塔、烟柱、巨橡树冠、整根石柱、图书馆尖顶、引路塔……），所以站在城堡里也能看到世界在远处展开；信标的动画（灯塔光束、烟、夜里的光晕）常驻运行。
- **旧世界按体量剔除**：把场景顶层节点（遇到半径 > 150 的大组就下钻一层）登记包围球，小屋 600 米外就关、大建筑最远 1150 米；站得高时额外视距按体量平方折算。
- **合并与实例化**：每个镇的碎网格在装配结束时按材质烘合（`compactGroup`，已修成会跳过 `InstancedMesh`）；重复的小东西（芦苇、鱼干、羊、柱子、台阶、盾牌……）全部走 `InstancedMesh`；人物每人从十几个网格烘成约 6 个（哑光 / 金属两份顶点色材质）；全局材质去重把 4845 个等价材质并成 231 个。
- **动态分辨率**：大屏（视网膜 / 4K）上瓶颈是填充率而不是绘制调用（CPU 只要 5 ms，GPU 却可能二十多 ms）。渲染循环里监测帧间隔，持续低于约 52 帧就把像素比降一档（1.5 → 1.25 → 1.0），一分钟后再试着升回去；开场八秒、切标签页、一次性卡顿不计入。
- **启动**：十个镇的装配约 130 ms，页面导航到首帧前约 670 ms。

### 生气：粒子、风与镇上的动静

通用工具都在 `kit.js`，十个镇和旧世界共用：

| 工具 | 做什么 |
|---|---|
| `createEmitter`（镇内是 `T.emitter`） | 一个 `Points` + 小着色器：火星、水雾、落叶、尘土、气泡、萤火、飘落的纸页……；支持重力 / 风 / 淡入淡出 / 变大变小，`night: 'only' \| 'day'` 控制只在夜里或白天出现，`gate(t)` 让粒子只在某个瞬间喷发（锤子落下才迸火星） |

## 场景中的活物

- **城防守军** — 四面城墙走道上有 14 名士兵（长枪 / 戟 / 弓，锅盔与桶盔，部分持盾），其中 2 名沿墙来回巡逻
- **城门守卫** — 门楼平台 3 名、门洞内 2 名
- **庭院平民** — 8 名定点村民（兜帽 / 布衣）+ 2 名走动的村民
- **护城河小船** — 4 条小船绕城缓行，随波起伏；带划桨与船夫，船首挂灯笼，入夜自动点亮并在水面留下暖色倒影
- **零碎道具** — 木桶、板条箱、草垛散落在庭院

## 昼夜作息

场景里有一部自己的时间：一小时约 40 秒，左下角的挂钟走得就是它。

- **摊位开合** — 天亮时布篷从后梁展开、货品摆上柜台；天黑后布篷卷起、货品收走、柜台盖上粗麻苫布
- **镇民回家** — 摊主、顾客、铁匠、酒客、神职和村外的农夫都登记了"工作点 + 家门"。天黑后各自走回家门口淡出，天亮再走回原处；酒客走得最晚
- **整点钟声** — 每到整点，钟楼里的铜钟摆动三下（集日四下），钟室四面透出暖光，左下角挂钟同步鸣响
- **街灯与火盆** — 入夜路灯灯罩发光、火盆烧旺、窗户全部点亮；集日的彩旗与五月柱一直留到收市
- **点光源池** — 全场的火把、街灯与火盆加起来六十多盏，每盏都会进所有材质的逐像素光照循环，全开帧率会掉到个位数。所以只留离镜头最近的二十四盏（小屏十四盏）真正点亮，远处那些本来就照不到跟前。灯罩自身的光晕与窗户自发光不受影响，夜里看过去仍然满城灯火

- `priory_outskirts.js` — 修道院外围五景：圣泉、什一税谷仓、济贫院、石匠场（两级采石坑）、隐士居
- `tournament_outskirts.js` — 比武场外围五景：校场、马市、场外集市、甲胄匠工棚、伤兵帐
- `inn_outskirts.js` — 客栈外围五景：渡口、路边神龛、篝火营地、货栈、荒村

- `tournament_outskirts2.js` — 比武场第二圈五景：牧马场、箭术场、木料场、马具匠工坊、老骑士宅
- `inn_outskirts2.js` — 客栈第二圈五景：收税关卡、瞭望塔、朝圣者病舍、水磨人家、绞架
- `nature.js` — 自然景观：按折线生成的大河、噪声岩块叠出的瀑布、极坐标高度场生成的山体、湖泊、花甸，以及会动的水鸟 / 鱼群 / 虫群（后三个返回 `update(dt, elapsed)` 交给主循环驱动）
- `town2.js` — 河东渡口镇：木栈桥码头、鱼市、摆渡小屋与渡船、河畔货栈、洗衣石阶、河畔水磨、石拱镇门、镇上的零碎
- `world.js` — 世界蓝图（纯数据）：世界半径、海、十镇选址、主干道折线与样条平滑、禁种区；`main.js` 在搭地面、种树之前就要用，所以不依赖 THREE
- `kit.js` — 村镇建造工具箱：带种子的随机数、调色板、参数化房屋 / 屋顶 / 栅栏 / 栈桥、阶梯山墙、渔网、船锚、实例化散布、轻量绵羊、带状地面等
- `expansion.js` — 外环十镇的装配：海与沙滩、主干道、每个镇的 `T` 接口（摆房子、登记地标、挂灯、放人、加动画、信标、常驻环境物）、可见性剔除、炊烟
- `towns/*.js` — 十个镇各一个模块（`harbor / mining / vintner / oak / wool / sky / marsh / frost / scholar / bazaar`），`towns/index.js` 是建造函数表
- `ambience.js` — 跟着镜头注视点走的环境粒子（落叶、浮尘、萤火）
- `minimap.js` — 小地图：静态底图预渲染，动态只补画标记与相机朝向，点击飞行
- `main.js` — 场景搭建（城墙、角塔、主楼、城门楼、吊桥、庭院、村落、镇中心、工匠区、要塞、修道院、比武场、客栈、三十处外围场景、河东的山水与第二座镇子、树林）、道路与两座石桥的接驳、人物与船只的排布调度、昼夜作息与钟声、点光源池、拾取交互、渲染循环
- `scripts/serve-nocache.py` — 起预览服务用的小脚本，在 `python -m http.server` 上加了 `no-store`；不加的话浏览器会按启发式缓存留住旧的 JS 模块
- `vendor/three` — three r169 的压缩构建与用到的两个 addons（OrbitControls、BufferGeometryUtils），随项目分发，无需 npm install，离线可跑

## 部署（Cloudflare Workers 静态资源）

项目是纯静态站点，`wrangler.jsonc` 把当前目录作为静态资源发布，`.assetsignore` 排除了脚本、文档和配置。在本项目目录下执行：

```
npx wrangler login      # 首次需要登录 Cloudflare
npx wrangler deploy
```
